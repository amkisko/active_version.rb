Recorded 2026-10-21. Multi-model engineering audit of active_version 2.0.0 leading into 2.1.0.

## Participants

Andrei Makarov (@amkisko)

## Decisions

- Fix confirmed high-severity correctness bugs in this release: fiber-local without_auditing/without_revisions, RequestStore-backed with_context!, at(time:) semantics, debounce earliest-state merge, audited migrator action mapping, mirror-column redaction skip, config error_behavior validation, Railtie load guard, Ruby floor 3.1.
- Defer to follow-up: PostgreSQL trigger payload shape vs Ruby readers, trigger identifier quoting, generator callback coexistence, revision generator placeholder columns, STI auditable_type, undo forward-truncate across instances, batch MAX version race, instrumentation payload size, coverage-gate reject_patterns for revision_queries and migrators.

## Effects

- Branch patch/engineering-audit-fixes implements the decided fixes with behavioural specs in spec/active_version/audit_hardening_spec.rb and related updates.
- VERSION and CHANGELOG set to 2.1.0 (2026-10-21).
