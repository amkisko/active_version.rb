## Dependency

- polyrun
- Constraint in this repo: gemspec `>= 2.2.0` (no upper bound)
- Lockfiles: gemfiles/rails72.gemfile.lock keeps polyrun 2.2.2

## Symptom

CI job `test (rails72, 3.2)` failed during Bundler install with exit code 5. Annotation: The process bundle failed with exit code 5.

## Evidence

- polyrun 2.2.2 and later declare `required_ruby_version >= 3.4`.
- polyrun 2.2.1 declares `required_ruby_version >= 3.1.0`.
- test.yml previously ran the rails72 appraisal on Ruby 3.2 while the lock had polyrun 2.2.2.
- Failure observed on main run https://github.com/amkisko/active_version.rb/actions/runs/35741117574 (commit 83defa7).

## Suggested fix

Move the rails72 CI matrix cell to Ruby 3.4 so current polyrun can install. Rails 7.2 supports Ruby 3.4. Do not pin polyrun below 2.2.2 for that appraisal.

## Effects

- `.github/workflows/test.yml` rails72 ruby_version is 3.4.
- polyrun upper-bound pins were not kept on appraisals.
