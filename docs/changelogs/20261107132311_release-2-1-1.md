# Release 2.1.1

## Participants

Andrei Makarov (@amkisko)

## Decisions

Cut 2.1.1 as a patch from `main`. Ship permanent audit/JSON/query/instrumentation hot-path optimizations and remove `AV_PRESSURE_BUILD` / pressure-cooker harness from lib. Keep `ActiveVersion.config.execution_scope` `:fiber` default as already shipped; do not add a second gem-level Fiber API. No custom C extension (`docs/reviews/20261106210000_pressure-optimizations-and-c-ext.md`). Leave tag and RubyGems publish to `make release` after a clean commit.

## Effects

VERSION is 2.1.1. CHANGELOG section dated 2026-11-07. PATH gem entries in `Gemfile.lock`, appraisal lockfiles, and `examples/rails_demo/Gemfile.lock` point at 2.1.1. Gem package builds and verifies at 78848 compressed bytes across 75 packaged paths (no `benchmarks/`). Maintainer `benchmarks/load.rb` / `pressure_probe.rb` and Make `bench-load` / `bench-fiber` stay repo-local outside the gem package; `benchmarks/output/` stays gitignored. Fiber store medians recorded in `docs/reviews/20261107114600_fiber-isolation-review.md`.

## Next

Push `main` (currently ahead of `origin/main`). Run `make release` to test, push the gem, tag `2.1.1`, and create the GitHub release. RubyGems still serves 2.1.0 until publish.
