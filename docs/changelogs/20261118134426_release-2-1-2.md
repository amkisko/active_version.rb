# Release 2.1.2

## Participants

Andrei Makarov (@amkisko)

## Decisions

Cut 2.1.2 as a patch from `main`. Ship the audit `json` / `jsonb` payload encoding fix so native columns store objects once and text-backed columns keep JSON strings. Leave tag and RubyGems publish to `make release` after a clean commit.

## Effects

VERSION is 2.1.2. CHANGELOG section dated 2026-11-18. PATH gem entries in `Gemfile.lock`, appraisal lockfiles, and `examples/rails_demo/Gemfile.lock` point at 2.1.2. Gem package builds and verifies at 78848 compressed bytes across 75 packaged paths (no `benchmarks/`).

## Next

Run `make release` to test, push the gem, tag `2.1.2`, and create the GitHub release. RubyGems still serves 2.1.1 until publish. Consumers on jsonb should re-check SQL key operators on new writes after upgrade.
